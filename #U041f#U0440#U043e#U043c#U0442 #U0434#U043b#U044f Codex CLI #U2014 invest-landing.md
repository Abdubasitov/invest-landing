Ты работаешь в корне проекта `invest-landing`.

Нужно создать первую полноценную версию официального инвестиционного лендинга Жалал-Абадской области на React.

## 1. Главная цель

Создай современный, официальный, визуально сильный лендинг инвестиционного проекта региона.

Это НЕ:
- CRM;
- личный кабинет инвестора;
- полноценный инвестиционный портал;
- старый типичный государственный сайт.

Это публичный маркетингово-информационный лендинг, задача которого:
1. представить инвестиционный потенциал Жалал-Абадской области;
2. показать основные отрасли;
3. показать реальные инвестиционные возможности;
4. повысить доверие к региону;
5. привести инвестора к контакту или будущему инвестиционному порталу.

Сейчас карту НЕ реализовывай. Она будет добавлена позже отдельным большим модулем.

КРИТИЧЕСКИ ВАЖНО:

Не использовать AI-generated фотографии как реальные.

Если у тебя есть web access:
1. ищи фотографии на официальных источниках:
   - gov.kg
   - invest.gov.kg
   - официальные сайты региональных органов;
2. либо используй фотографии с понятной лицензией;
3. для каждой фотографии сохрани источник.

`src/data/imageSources.ts`

с полями:

```ts
{
  image: "...",
  title: "...",
  sourceName: "...",
  sourceUrl: "..."
}
```

Если права на прямое скачивание изображения не очевидны — НЕ скачивай его автоматически.

В таком случае:
- используй аккуратный placeholder;
- сохрани URL источника;
- оставь понятный TODO.

Не хотлинь изображения с сомнительных сайтов.
